# cats-dogs-svm
# Cats vs Dogs Classification using SVM

This project implements a Support Vector Machine (SVM) to classify images of cats and dogs using the Kaggle dataset.

## 🚀 Features
- Image preprocessing (resize, grayscale)
- HOG feature extraction
- SVM training with scikit-learn
- Evaluation with accuracy, precision, recall, F1-score

## 📂 Dataset
Download the dataset from Kaggle: [Dogs vs Cats](https://www.kaggle.com/c/dogs-vs-cats/data)
